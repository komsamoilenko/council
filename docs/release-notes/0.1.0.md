# council 0.1.0

council is a local MCP server for cross-vendor AI consultations. It provides eight
tools for consultations, polling, cancellation, job listing, ledger inspection,
search and diagnostics, using your own vendor accounts. Supported consultation
legs are Claude Code, Codex and the Gemini API; echo supports zero-quota testing.

This release includes the platform layer, application launcher, configuration
outside the vault, multiple profiles, relocatable jobs and ledger, derived narrow
roots, integrity checks, secret redaction, environment filtering and shared fuses.
The Gemini API runs in a council-owned child, receives its key over stdin, uses
scoped proxy settings and supports Windows DPAPI key storage.

The complete installer verb set includes detection, planning, journalled apply
and recovery, verification, updates through git or zip, uninstall, prerequisite
and login guidance, key management, migration and task creation. It supports the
three host registrations, conditional English vault templates, marker merging,
whole-file backups with surgical host recovery, duplicate reports, cloud-sync
warnings and vault checks. The shared skill wrapper, documentation, personal-data
scanner without exemptions, release tooling, Tier-0, trust and installer tests
are included. The generic migration procedure preserves running jobs and stored
history while hosts move to the application launcher.

Windows is implemented. macOS and Linux ship honest stubs for process supervision,
OS secret storage and file attributes: they boot in `unsupported-platform` mode
and provide diagnostics and read operations, but cannot start consultations or
actively poll or cancel jobs. Terminal results remain readable. Runtime checks
have used Node 24.11.1; the older proposed floor has not been established by a
launcher test on that version.

The Antigravity adapter ships disabled because the vendor's terms restrict access
through third-party tools. council does not install or enable it. The supported
Gemini route is the Gemini API with your own API key. See [NOTICE.md](../../NOTICE.md)
for the terms context and why the adapter remains disabled.
